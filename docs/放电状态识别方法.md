# 基于电流动态行为的高低压复合放电状态识别

当前实现是 `dynamic-screening-v4` 动态筛查与 `batch-morphology-v3` 整批形态学习，尚未完成实验标签训练或独立准确率验证。四类输出均为自动建议，原动态筛查的 `abnormal_discharge` 同时接纳证据不足的待复核周期，不能等同于已经确认的加工异常；整批输出通过 `automatic_state=undetermined` 单独表达证据不足。

## 5.1 波形数据采集与预处理

沿用 `data_loader.py`：第一列为数值秒时间，电压/电流通道通过名称或单位识别，输出 `time/voltage/current` 标准列。读取器在本任务中未重新设计；带前导元数据、多种分隔符、非秒时间单位或歧义通道名称的导出格式仍需另行验证。电流必须已正确标定到 A，电压必须为 V。

周期采样率取时间差中位数的倒数，不硬编码 1 MHz。NaN/Inf、非递增时间、相对采样间隔偏差超过 1% 或少于 32 点的周期保留质量原因并建议待复核异常，不默默删点或插值。

分析用五点中值滤波抑制孤立采样尖峰，原始输入和样本图保持不变。这可能削弱数个采样点以内的真实高频微脉冲。单凭窄脉冲形态不能确定是干扰还是实际微放电。

保留有符号电流用于转折、变点与事件分析；幅值峰峰值和标准差使用绝对值，另输出有符号版本。只有传入经测定的 `--current-offset` 才校正电流零点。用于描述形态的 `baseline_current_A` 是本周期主电平/中位数，**不是自动测定的零电流值**，不会从功率、电流幅值或积分中自动扣除。

## 5.2 基于频域与波形特征的周期自动检测

保留现有 `周期检测.py`：前、中、后三个区域低通滤波，FFT 实现自相关，在 0.1–10 ms 区间搜索自相关峰，取区域估计点数的中位数，再在预测位置附近寻找电压变化边沿。不要求人工指定周期长度或点数。

较强边沿未必总是同一物理相位，应检查周期叠加图、相邻边界和单周期波形。如果短路跃迁恰好在切割边界，周期内可能没有跃迁前证据。该周期不会被强行归为短路。

自 v3 起可通过 `--cycles` 复用**同一原始 CSV** 先前自动检测的周期表，让算法比较保持相同边界和编号。不可将其他实验的周期表直接套用到新数据。v4 新增 `--expected-source-sha256`，在波形处理前核对已知源文件哈希，不匹配时停止且不覆盖结果。主程序保存实际和预期 SHA-256、核对结果、点数、时间范围和边界来源到 `运行来源.json`。源文件哈希用于身份核对，不证明边界物理相位正确；旧 v2 没有这些来源指纹，不能仅凭特征表证明两个 CSV 完全相同。

## 5.3 噪声、观测电平尺度与动态特征

局部统计尺度仍按 12 个窗口计算：

\[
\sigma_{MAD}=Q_{0.25}\left[\frac{1.4826\,MAD(\Delta^2 x)}{\sqrt{6}}\right].
\]

它依赖局部近似独立噪声。在大量完全相等的量化平台上，二阶差分 MAD 可退化为 0。v2 将数值精度下限直接用于 SNR，使固定偏置和小离散跳变被放大为极大的活动证据。v3 保留 `noise_current_mad` 记录原始结果，不把退化值当成可靠噪声估计。

对至少三个重复电平、独立电平数不超过点数一半的波形，检查相邻电平间距是否在数值容差内为共同网格间距 q 的整数倍。若相容，则采用：

\[
\sigma_{effective}=\max(\sigma_{MAD},q/\sqrt{12}).
\]

q 是**观测电平网格间距**，不是已知硬件 ADC 的 LSB；均匀量化误差是显式的保守模型假设，不代表每次 q 幅度变化都是噪声。两个电平不足以确定 q，避免将真实的大阶跃直接当作分辨尺度。硬件量程、传感器增益、导出处理和无电流参考记录仍须独立核实。

`current_noise_model` 区分 `measured_mad`、`quantized_resolution_bound` 和 `numerical_floor`。`noise_current` 是判据使用的有效尺度，不能把它和旧 v2 的同名列直接当成同一定义比较。

v4 增加 `current_scale_reliable`。存在原始电流事件、而尺度来源只有 `numerical_floor` 时，数值舍入下限不能代表测量噪声，`activity_snr`、`jump_snr` 和 `post_current_snr` 输出 NaN，物理分类返回 `unreliable_current_noise_scale` 待复核，不用巨大虚假 SNR 支持开路、有效放电或短路。周期 359 的双电平窄事件属于这一情况；两个电平仍不足以独立推定硬件 q。保留原始尺度和形态特征用于追溯，不凭空补造噪声或硬件分辨率。

主要特征：

| 特征 | 含义 |
| --- | --- |
| `Ipeak`, `Irms`, `I_pp`, `I_std` | 校正电流幅值的峰值、RMS、峰峰值、标准差 |
| `signed_I_pp`, `signed_I_std` | 有符号电流变化描述 |
| `robust_I_pp` | 滤波后有符号电流 99%–1% 分位跨度 |
| `noise_current_mad`, `current_level_step_A`, `current_noise_model` | 原始 MAD、观测网格与尺度来源 |
| `current_scale_reliable` | 电流尺度是否可用于动态判据；数值下限加事件不可信 |
| `change_count` | 相邻变化超过噪声界的次数，仅作描述 |
| `reversal_count`, `oscillation_index` | 滞回转折次数及包含转折的窗口占比 |
| `oscillation_span_ratio` | 首末显著转折的跨度 |
| `oscillation_support_fraction` | 电流实际偏离形态基线超过有效尺度界的时间占比 |
| `raw_event_count`, `raw_event_fraction` | 原始数据偏离主电平的事件数和持续时间占比 |
| `narrow_event_count`, `max_event_width_samples` | 不超过五点的事件数和最大事件宽度 |
| `bounded_excursion_span_fraction` | 在周期内部起止、返回形态基线的最长显著事件跨度 |
| `paired_response_fraction` | 显著电流事件与电压下降证据的时间重叠占比 |
| `edge_pre_current_A`, `edge_post_current_A` | 周期两端各 5% 区间的电流中位数，作为形态背景 |
| `edge_reference_sample_count`, `edge_reference_stable` | 每端背景样本数和稳定性支持 |
| `edge_excursion_start_index`, `edge_excursion_end_index` | 优先选取有联合证据的完整事件的周期内索引，末端不包含；无支持候选时保留最长诊断项 |
| `edge_candidate_event_count`, `edge_supported_event_count` | 完整候选数和分别满足同事件联合条件的数量，不跨事件拼接支持 |
| `edge_excursion_span_fraction`, `edge_paired_response_fraction` | 同一完整事件跨度与电压响应重叠占比 |
| `edge_pulse_response_supported` | 稳定背景、完整宽事件与同事件电压响应均获支持 |
| `step_bic_gain`, `transition_fraction` | 单变点模型支持与跃迁宽度 |
| `pre_sample_count`, `post_sample_count`, `plateau_supported` | 实际平台样本数和支持是否充分 |
| `post_current_std`, `post_voltage_std` | 后段波动；样本不足记 NaN，不能用 0 代表稳定 |

周期首尾各 5% 不参与转折计数，减少切割/复位边沿影响。滞回转折要求累计反向变化超过 `4√2σeffective`，能够检测缓慢振荡而不依赖单点最大导数。v3 进一步要求显著变化在时间上有支持，不能仅凭分散的几个尖峰覆盖许多窗口就称为持续振荡。

事件分析仅合并相隔不超过五点的短暂过零，不把相距很远的尖峰拼成长放电段。电压响应使用相对高电平参考与噪声界；时间重叠不等于严格因果或电压—电流耦合证明，驱动响应和测量串扰仍可能满足，需要实验标签验证。

v4 额外检查两端稳定背景包络。周期首尾各取 5% 区间，至少各 32 点，且各端标准差不超过 `4σeffective`，才允许使用背景。令两端中位数为 `bpre`、`bpost`，背景区间为 `[min(bpre,bpost), max(bpre,bpost)]`，在区间两侧再扩展 `4σeffective`；只有离开扩展区间的部分才构成该规则的事件证据。这可避免把两个不同背景之间的一次换挡误当作宽放电。

事件必须在首尾背景区之间完整起止，按五点间隙规则合并后逐个检查。单个事件跨度至少为全周期的 25%，其自身显著电流部分与电压响应的重叠占内部分析区至少 25%，才取得联合支持。优先选取有联合支持的候选；多个支持候选取最长者，无支持候选时保留最长事件作诊断。最长事件没有电压响应时不会遮蔽另一个满足条件的事件，其他事件也不会被借来凑支持。两端不稳、事件被周期边界截断、只在两端背景之间变化、平电压或错时电压响应，均不能获得这一新增建议。两端背景不是测定零点，这一模型不减背景、不改原始幅值和能量积分。

单变点常值模型与常值/线性趋势模型通过累计和比较：

\[
G=N\log\frac{SSE_{baseline}+N\sigma_{effective}^2}{SSE_{step}+N\sigma_{effective}^2}-\log N.
\]

`G>0` 只表示变点模型得到支持。排除过渡和复位区后，前后各至少 32 点且后平台占周期至少 40%，才允许把后段用于短路稳定性证据。v2 极短尾段曾被压成一个点、标准差记 0；v3 使用真实切片长度，样本不足输出 NaN，短路分数为 0。

`energy_J` 为 `∫|UI|dt` 的活动能量代理，`energy_signed_J` 为有符号积分。使用实际时间轴，均不参与核心分类。净加工能量仍取决于标定、极性定义和功率边界。`di_dt_max`、原固定幅值的 `I_rise_time` 已退出输出；`current_high_*` 仅保留兼容描述量，不参与分类和候选评分。

## 5.4 四类状态建议

特征版本继续为 v4，决策修订 `dynamic-decision-v4.1` 按如下顺序处理：

1. 数据质量异常 → `abnormal_discharge`，保留原因。
2. 存在事件但电流尺度仅为数值舍入下限 → `abnormal_discharge / unreliable_current_noise_scale`。尺度缺失不能推成强活动证据。
3. 平台证据充分、电流显著跃迁后稳定、电压同步下降后稳定、没有持续振荡 → `short_circuit` 建议。稳定长平台是否是真短路仍需物理标注。
4. 有受时间占比支持的持续电流振荡，并有显著电压响应 → `effective_discharge` 建议。
5. 存在周期内部起止的较长电流事件、与电压响应时间重叠充分 → `effective_discharge` 建议。这允许单次宽脉冲/多电平包络，不要求每次有效放电都是重复正弦振荡。
6. 两端稳定背景包络之外存在完整宽事件，且同一事件的电压响应支持充分 → `effective_discharge / complete_excursion_outside_edge_backgrounds` 建议。该分支处理周期前后背景不同而全周期主电平不足以描述事件的情况。
7. 缺乏上述联合支持且活动低于有效尺度、仍存在未分辨的量化事件 → `abnormal_discharge / resolution_limited_events`。无法据此确认开路，也不把窄事件自动视为真实放电或噪声。
8. 缺乏联合活动支持、电流在可靠的背景尺度内且存在施加电压证据 → `open_circuit` 建议。无电压无电流不直接等同于开路。
9. 其余非零电流、混合形态或证据不足 → `abnormal_discharge` 待复核。

`short_score` 是十项形态条件的满足比例，不是概率。平台证据不足或分辨尺度内无法确认活动时为 0。候选排序排除开路、损坏数据和零分记录，不为凑数量生成候选。图片标题含模型版本，候选图和状态图均使用独立批次，避免旧图被当作新运行结果。

此顺序修订将局部事件证据与全周期平均活动分开。背景近零的矩形事件占空比为 \(d\) 时，全周期 RMS 约为事件幅值的 \(\sqrt d\) 倍。一个持续 28%、幅值 \(2q\) 的构造事件，在假设尺度 \(q/\sqrt{12}\) 下局部幅度比约为 6.93，满足原来的显著事件条件；全周期活动比约为 3.67，却会被旧版前置的 4 倍 RMS 分支提前返回。修订保留原幅度、持续时间和电压联合条件，先检查已有支持；单个网格幅值、分散短事件、缺少电压响应或不可信尺度仍不能据此获得有效建议。该构造证明判据顺序问题，不能证明实际待定周期已经发生物理误判。

模型参数仍是显式假设：4 倍尺度、五点中值滤波、12 窗口、至少 4 转折、25% 动态支持、40% 后平台、相对电压下降至前水平一半、32 点最小样本等。v4 沿用这些参数，新增背景定义和同一事件支持约束，不为制造类别数量逐张调阈值；仍须用跨实验标签验证，不能宣称无参数或已训练成四类机器学习模型。

## 5.5 统计、逐点复核与后续学习

输出：

- `放电状态结果.csv`：四类建议、特征、质量/分辨尺度来源、分类理由、边界、版本与复核标记。
- `识别模型参数.json`、`运行来源.json`：模型配置、零点校准、源文件指纹及来源，明确标签验证尚未完成。
- `状态特征统计.csv`、`各状态特征均值.csv`：有效样本数与动态特征分布，缺失平台标准差不会当作 0 参与平均。
- `短路候选排序.csv` 和 `短路候选图/批次目录/`：有足够平台支持的待复核候选。
- `状态验证/批次目录/`：每类默认 10 图、人工复核清单和样本数量统计；不足按实报告，不强制四类出现。

`export_review_cycles.py` 可从旧结果边界导出少量完整周期，保留原始时间、电压、电流、编号和源索引。不重检测边界、不平滑、不施加额外零点校准。原始大 CSV 无需整体转移，即可检查单点/几点评估、量化电平、宽脉冲与电压响应。导出来源 JSON 保留源文件 SHA-256 与模型表来源。

`reclassify_features.py` 在特征定义不变时，读取完整 v4 特征及生成时记录的 `DynamicConfig`，应用当前决策修订后重新学习整批，保存新旧状态和原因对照、输入指纹及 `decision_rule_version`。不重新提取波形、不修改边界或输入表，不从缺失配置猜测原判据；v3 仍不能通过该入口补造 v4 特征。`diagnose_pending.py` 独立汇总待定原因、有限特征分位数与缺失数量，优先收集可能被低活动门控遮蔽的联合事件代表，然后覆盖各种原因/群组并补充最长原始事件。选样只收集诊断证据，不改标签。使用预期源文件指纹核对后可导出这些完整原始周期。

该小 CSV 中各周期之间不连续，应按 `cycle_id` 分组逐周期复核，不能把整张表直接当作连续实验信号重新做 FFT 周期检测。

旧 v2 特征不含事件时间支持、观测网格与有效平台样本数，不能从旧 CSV 直接生成可信 v3 分类，必须从原始周期重新提取。

旧 v3 特征也没有两端背景包络，不能只修改版本字符串或状态列生成 v4 结果。v4 应从原始 CSV 重跑，复用原自动边界以保持编号；单独运行批次学习不会从特征表恢复原始事件起止或背景。`batch-morphology-v3` 仍接受完整的单一 v3 特征表，使用旧特征空间聚类，但不声称它已有 v4 物理证据；同一批次混合 v3/v4 或声明 v4 但缺少新特征时明确报错。

人工标注应结合波形、设备日志、加工状态及采集设置。无法确认时保留 `uncertain`，不要勉强归为开路或有效。后续监督学习可使用这些稳定特征，按实验文件/工况划分训练、验证和测试，防止相邻周期泄漏；报告每类 precision/recall/F1、混淆矩阵和未知样本比例。

## 当前验证范围

### 整批特征学习扩展

主程序默认在 v4 特征后运行 `batch-morphology-v3`，不使用人工标签，不改变原始电流标定、周期边界、输入动态筛查状态或原判别原因。`learn_batch.py` 可单独读取单一版本的已有 v3/v4 结果。`automatic_state` 明确区分物理状态建议和 `undetermined`；因此原筛查列中的异常/待复核，不会全部被报告为已判定异常加工。

学习空间包括电流活动/动态幅值噪声比的 log1p、事件持续占比、振荡时间支持、宽事件跨度、电压响应重叠、跃迁及平台特征。使用整批中位数与 IQR 缩放；IQR 退化时使用标准差，数值常值列剔除。平台统计缺失采用中位填充并附带缺失指示，不用 0 冒充稳定平台。有效样本按周期编号排序，最多均匀取 20000 个拟合样本。

v4 输入额外加入两端背景包络的事件跨度、同事件电压重叠及背景稳定性。v3 输入不补造这三项，不把缺失包络全部填 0 冒充不存在事件。改变特征空间会改变 BIC 选择和形态群组编号，群组不能跨版本按数字直接对应。

比较 1–8 组全协方差高斯混合模型的 BIC；候选组数同时受拟合样本量约束，且每组至少需 20 个拟合样本支持，未收敛的模型不采用。协方差正则项为 0.05，每个候选使用 3 次初始化、固定随机种子 42。群组数是波形形态数，不是四类加工状态数；一个物理状态可以包含多个形态群。

对已获逐周期物理证据支持的建议，混合分布的典型归属提供批次一致性证据。归属阈值 0.8 仅用于重叠形态群的抽查优先级；归属概率不能解释为状态准确率。以保留特征维度的卡方 0.999 分位描述群内马氏距离离群，依赖近似高斯和协方差模型假设，未作实测概率校准。离群仅提高抽查优先级，不单独撤销已有动态证据支持的建议，也不将稀少的真实放电强行认作异常。少于 32 个有效周期、特征常值或无合格拟合模型时明确回退到输入版本的动态证据，并保留学习失败/不足原因。

若电流包含事件，而尺度模型仅为 `numerical_floor`，舍入下限不能当作实测噪声，该周期排除出拟合并保留待定；v4 已在特征提取时将相应 SNR 记为缺失，批次层同时识别旧 v3 表中的不可信巨大数值。不能通过直接猜测量化尺度重新计算缺失的波形特征。原始完整零电流常值没有事件时仍可参与描述。逐项审计记录原始最长事件、内部有界事件与 v4 两端背景支持的差异；长原始事件不等于已确认的长加工放电。

这实现的是“整批自动形态学习 + 物理证据命名 + 不确定性保留”，不是已有四类训练标签的监督分类器。后续可靠四类识别仍需跨实验参考和独立验证。用户确认的有效宽事件说明有效加工不必呈现反复振荡，但单个开发期确认样本不构成准确率评估。
