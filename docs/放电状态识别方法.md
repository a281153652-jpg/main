# 基于电流动态行为的高低压复合放电状态识别

当前实现是 `dynamic-screening-v3`，是可解释的物理特征筛查模型，尚未完成实验标签训练或准确率验证。四类输出均为自动建议，`abnormal_discharge` 同时接纳证据不足的待复核周期，不能等同于已经确认的加工异常。

## 5.1 波形数据采集与预处理

沿用 `data_loader.py`：第一列为数值秒时间，电压/电流通道通过名称或单位识别，输出 `time/voltage/current` 标准列。读取器在本任务中未重新设计；带前导元数据、多种分隔符、非秒时间单位或歧义通道名称的导出格式仍需另行验证。电流必须已正确标定到 A，电压必须为 V。

周期采样率取时间差中位数的倒数，不硬编码 1 MHz。NaN/Inf、非递增时间、相对采样间隔偏差超过 1% 或少于 32 点的周期保留质量原因并建议待复核异常，不默默删点或插值。

分析用五点中值滤波抑制孤立采样尖峰，原始输入和样本图保持不变。这可能削弱数个采样点以内的真实高频微脉冲。单凭窄脉冲形态不能确定是干扰还是实际微放电。

保留有符号电流用于转折、变点与事件分析；幅值峰峰值和标准差使用绝对值，另输出有符号版本。只有传入经测定的 `--current-offset` 才校正电流零点。用于描述形态的 `baseline_current_A` 是本周期主电平/中位数，**不是自动测定的零电流值**，不会从功率、电流幅值或积分中自动扣除。

## 5.2 基于频域与波形特征的周期自动检测

保留现有 `周期检测.py`：前、中、后三个区域低通滤波，FFT 实现自相关，在 0.1–10 ms 区间搜索自相关峰，取区域估计点数的中位数，再在预测位置附近寻找电压变化边沿。不要求人工指定周期长度或点数。

较强边沿未必总是同一物理相位，应检查周期叠加图、相邻边界和单周期波形。如果短路跃迁恰好在切割边界，周期内可能没有跃迁前证据。该周期不会被强行归为短路。

v3 可通过 `--cycles` 复用**同一原始 CSV** 先前自动检测的周期表，让算法比较保持相同边界和编号。不可将其他实验的周期表直接套用到新数据。主程序保存输入 SHA-256、点数、时间范围和边界来源到 `运行来源.json`，用于后续追溯。旧 v2 没有这些来源指纹，不能仅凭特征表证明两个 CSV 完全相同。

## 5.3 噪声、观测电平尺度与动态特征

局部统计尺度仍按 12 个窗口计算：

\[
\sigma_{MAD}=Q_{0.25}\left[\frac{1.4826\,MAD(\Delta^2 x)}{\sqrt{6}}\right].
\]

它依赖局部近似独立噪声。在大量完全相等的量化平台上，二阶差分 MAD 可退化为 0。v2 将数值精度下限直接用于 SNR，使固定偏置和小离散跳变被放大为极大的活动证据。v3 保留 `noise_current_mad` 记录原始结果，不把退化值当成可靠噪声估计。

对至少三个重复电平、独立电平数不超过点数一半的波形，检查相邻电平间距是否在数值容差内为共同网格间距 q 的整数倍。若相容，则采用：

\[
\sigma_{effective}=\max(\sigma_{MAD},q/\sqrt{12}).
\]

q 是**观测电平网格间距**，不是已知硬件 ADC 的 LSB；均匀量化误差是显式的保守模型假设，不代表每次 q 幅度变化都是噪声。两个电平不足以确定 q，避免将真实的大阶跃直接当作分辨尺度。硬件量程、传感器增益、导出处理和无电流参考记录仍须独立核实。

`current_noise_model` 区分 `measured_mad`、`quantized_resolution_bound` 和 `numerical_floor`。`noise_current` 是判据使用的有效尺度，不能把它和旧 v2 的同名列直接当成同一定义比较。

主要特征：

| 特征 | 含义 |
| --- | --- |
| `Ipeak`, `Irms`, `I_pp`, `I_std` | 校正电流幅值的峰值、RMS、峰峰值、标准差 |
| `signed_I_pp`, `signed_I_std` | 有符号电流变化描述 |
| `robust_I_pp` | 滤波后有符号电流 99%–1% 分位跨度 |
| `noise_current_mad`, `current_level_step_A`, `current_noise_model` | 原始 MAD、观测网格与尺度来源 |
| `change_count` | 相邻变化超过噪声界的次数，仅作描述 |
| `reversal_count`, `oscillation_index` | 滞回转折次数及包含转折的窗口占比 |
| `oscillation_span_ratio` | 首末显著转折的跨度 |
| `oscillation_support_fraction` | 电流实际偏离形态基线超过有效尺度界的时间占比 |
| `raw_event_count`, `raw_event_fraction` | 原始数据偏离主电平的事件数和持续时间占比 |
| `narrow_event_count`, `max_event_width_samples` | 不超过五点的事件数和最大事件宽度 |
| `bounded_excursion_span_fraction` | 在周期内部起止、返回形态基线的最长显著事件跨度 |
| `paired_response_fraction` | 显著电流事件与电压下降证据的时间重叠占比 |
| `step_bic_gain`, `transition_fraction` | 单变点模型支持与跃迁宽度 |
| `pre_sample_count`, `post_sample_count`, `plateau_supported` | 实际平台样本数和支持是否充分 |
| `post_current_std`, `post_voltage_std` | 后段波动；样本不足记 NaN，不能用 0 代表稳定 |

周期首尾各 5% 不参与转折计数，减少切割/复位边沿影响。滞回转折要求累计反向变化超过 `4√2σeffective`，能够检测缓慢振荡而不依赖单点最大导数。v3 进一步要求显著变化在时间上有支持，不能仅凭分散的几个尖峰覆盖许多窗口就称为持续振荡。

事件分析仅合并相隔不超过五点的短暂过零，不把相距很远的尖峰拼成长放电段。电压响应使用相对高电平参考与噪声界；时间重叠不等于严格因果或电压—电流耦合证明，驱动响应和测量串扰仍可能满足，需要实验标签验证。

单变点常值模型与常值/线性趋势模型通过累计和比较：

\[
G=N\log\frac{SSE_{baseline}+N\sigma_{effective}^2}{SSE_{step}+N\sigma_{effective}^2}-\log N.
\]

`G>0` 只表示变点模型得到支持。排除过渡和复位区后，前后各至少 32 点且后平台占周期至少 40%，才允许把后段用于短路稳定性证据。v2 极短尾段曾被压成一个点、标准差记 0；v3 使用真实切片长度，样本不足输出 NaN，短路分数为 0。

`energy_J` 为 `∫|UI|dt` 的活动能量代理，`energy_signed_J` 为有符号积分。使用实际时间轴，均不参与核心分类。净加工能量仍取决于标定、极性定义和功率边界。`di_dt_max`、原固定幅值的 `I_rise_time` 已退出输出；`current_high_*` 仅保留兼容描述量，不参与分类和候选评分。

## 5.4 四类状态建议

按如下顺序处理：

1. 数据质量异常 → `abnormal_discharge`，保留原因。
2. 活动低于有效尺度、且有未分辨的量化事件 → `abnormal_discharge / resolution_limited_events`。无法据此确认开路，也不把窄事件自动视为真实放电或噪声。
3. 电流在可靠的背景尺度内且存在施加电压证据 → `open_circuit` 建议。无电压无电流不直接等同于开路。
4. 平台证据充分、电流显著跃迁后稳定、电压同步下降后稳定、没有持续振荡 → `short_circuit` 建议。稳定长平台是否是真短路仍需物理标注。
5. 有受时间占比支持的持续电流振荡，并有显著电压响应 → `effective_discharge` 建议。
6. 存在周期内部起止的较长电流事件、与电压响应时间重叠充分 → `effective_discharge` 建议。这允许单次宽脉冲/多电平包络，不要求每次有效放电都是重复正弦振荡。
7. 其余非零电流、混合形态或证据不足 → `abnormal_discharge` 待复核。

`short_score` 是十项形态条件的满足比例，不是概率。平台证据不足或分辨尺度内无法确认活动时为 0。候选排序排除开路、损坏数据和零分记录，不为凑数量生成候选。图片标题含模型版本，候选图和状态图均使用独立批次，避免旧图被当作新运行结果。

模型参数仍是显式假设：4 倍尺度、五点中值滤波、12 窗口、至少 4 转折、25% 动态支持、40% 后平台、相对电压下降至前水平一半、32 点最小样本等。v3 没有逐张图调整这些参数来制造类别数量，而是修复尺度退化与形态证据定义；仍须用跨实验标签验证，不能宣称无参数或已训练成机器学习模型。

## 5.5 统计、逐点复核与后续学习

输出：

- `放电状态结果.csv`：四类建议、特征、质量/分辨尺度来源、分类理由、边界、版本与复核标记。
- `识别模型参数.json`、`运行来源.json`：模型配置、零点校准、源文件指纹及来源，明确标签验证尚未完成。
- `状态特征统计.csv`、`各状态特征均值.csv`：有效样本数与动态特征分布，缺失平台标准差不会当作 0 参与平均。
- `短路候选排序.csv` 和 `短路候选图/批次目录/`：有足够平台支持的待复核候选。
- `状态验证/批次目录/`：每类默认 10 图、人工复核清单和样本数量统计；不足按实报告，不强制四类出现。

`export_review_cycles.py` 可从旧结果边界导出少量完整周期，保留原始时间、电压、电流、编号和源索引。不重检测边界、不平滑、不施加额外零点校准。原始大 CSV 无需整体转移，即可检查单点/几点评估、量化电平、宽脉冲与电压响应。导出来源 JSON 保留源文件 SHA-256 与模型表来源。

该小 CSV 中各周期之间不连续，应按 `cycle_id` 分组逐周期复核，不能把整张表直接当作连续实验信号重新做 FFT 周期检测。

旧 v2 特征不含事件时间支持、观测网格与有效平台样本数，不能从旧 CSV 直接生成可信 v3 分类，必须从原始周期重新提取。

人工标注应结合波形、设备日志、加工状态及采集设置。无法确认时保留 `uncertain`，不要勉强归为开路或有效。后续监督学习可使用这些稳定特征，按实验文件/工况划分训练、验证和测试，防止相邻周期泄漏；报告每类 precision/recall/F1、混淆矩阵和未知样本比例。

## 当前验证范围

v3 的合成回归包括负电流振荡、量化窄事件、多电平振荡、宽脉冲电压响应、单点平台、极性/增益变化、零点校准、时间积分、数据质量、边界复用、原始周期导出及来源指纹。合成测试验证代码行为，不是实验准确率。截图和旧特征表能够定位算法缺陷，不能恢复逐点事件宽度，也不能代替实验标签。

历史 v2 在当前云实例中通过 26 项合成测试，并执行过 128,820 点合成 CSV 的全流程（58 个完整周期，中位周期 2147 点）。历史 v2 的千万点状态模块测量为 4657 个完整周期、约 5.832 秒、峰值 RSS 约 719.4 MiB；不含 CSV 读取、FFT 检测和绘图。这些历史数据不作为 v3 的耗时或真实分类准确率。

当前 v3 通过 38 项回归测试，并执行了 128,820 点合成 CSV 的真实主程序（含自动周期检测、统计、图像及来源记录）。另在 10,000,000 点合成混合事件信号上单独运行状态模块，处理 4657 个完整周期、约 15.815 秒，整个进程峰值 RSS 约 849.2 MiB；不含 CSV 读取、FFT 和绘图。合成信号含已构造的宽事件与未确认窄事件，只验证相应模型行为，不代表真实实验中的类别数量或识别准确率。
