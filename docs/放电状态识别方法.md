# 基于电流动态行为的高低压复合放电状态识别

本实现是可解释的物理特征筛查模型 `dynamic-screening-v2`，尚未用实验标签训练或验证。四类输出均为**自动建议**。合成波形通过测试，不能据此报告真实实验准确率，也不能确认截图中的 cycle 4582 或 cycle 2330 的物理状态。

## 5.1 波形数据采集与预处理

输入沿用 `data_loader.py` 的标准表：`time`（秒）、`voltage`（伏特）、`current`（安培）。CSV 的第一列须为数值时间，文件须具有可识别的电压、电流表头。此任务没有改变读取器，也没有验证带 Dewesoft 元数据前导行、非秒时间单位或各种分隔符的导出格式。

特别需要核实原实验中标为 `(V)` 的电流采集通道是否已应用传感器标定比例。未转换为安培时，输出电流和 `energy_J` 的物理单位不能直接成立。需要在采集/导出端完成标定或另行扩展读取器。

采样率取周期时间差的中位数的倒数，不再硬编码 1 MHz。过短、NaN/Inf、非递增时间、相对采样间隔偏差超过 1% 的周期输出异常建议，并保留 `data_quality`；程序不会默默删点、插值或缩短波形。

保留有符号电流做振荡/变点分析。峰值、幅值峰峰值和幅值标准差基于绝对值，同时输出 `signed_I_pp` 与 `signed_I_std`，防止过零信息丢失。分析用五点中值滤波抑制孤立采样尖峰，原始输入与绘图电流保持不变。该滤波可能削弱短于数个采样点的真实高频振荡，不能在不知道信号带宽的情况下把被滤掉的尖峰认定为噪声。

默认不猜测传感器零电流偏置。可以通过 `--current-offset` 提供从已确认无电流区测出的标定值；校正量保存为 `current_zero_offset_A`。偏置是标定量，不是分类电流阈值。如果存在未知偏置，无振荡的偏置电流会进入待复核异常类，而不是强行自动归入开路。样本图显示原始测量电流，分类特征使用校正电流。

## 5.2 基于频域与波形特征的周期自动检测

保留现有 `周期检测.py`：前、中、后三个区域低通滤波，FFT 实现自相关，在 0.1–10 ms 的搜索区间找自相关峰，取区域估计点数的中位数，再在预测边界附近寻找电压变化边沿。该搜索范围是现有算法的适用范围，不要求用户输入单周期点数。

本任务没有重新验证“2147 点、4659 周期”的实验结果。现有边界算法选择较强电压边沿，不一定始终对应相同物理相位；需要结合周期叠加图检查。如果短路跃迁恰好位于切割边界，周期内可能缺少跃迁前证据，新模型会保守地给出异常建议。当前不是对周期检测准确性的全面验证。

分类结果保存 `start_index/end_index`（右端不包含），候选图和状态图直接使用这些边界，不重复读取原始千万点文件、不重新检测周期。

## 5.3 单周期放电特征提取

对每个周期划分 12 个局部窗口，估计通道噪声：

\[
\sigma = Q_{0.25}\left[\frac{1.4826\,\mathrm{MAD}(\Delta^2 x)}{\sqrt{6}}\right].
\]

这依赖局部噪声近似独立的假设。低频相关噪声、强量化、滤波输出或整段都含高频动态时，该估计可能不准确。只有数值精度下限，不人为添加一个固定安培噪声底。

主要新增特征：

| 特征 | 定义/用途 |
| --- | --- |
| `I_pp`, `I_std` | 原始校正电流绝对值的峰峰值、标准差 |
| `signed_I_pp`, `signed_I_std` | 有符号电流变化描述 |
| `robust_I_pp` | 中值滤波后有符号电流的 99%–1% 分位跨度 |
| `change_count` | 周期中部相邻变化超过 `4√2σI` 的次数，仅作描述 |
| `reversal_count` | 累计反向变化超过 `4√2σI` 的滞回转折次数 |
| `oscillation_index` | 含显著转折点的窗口数 / 12 |
| `oscillation_span_ratio` | 首末显著转折间距 / 周期中部长度 |
| `activity_snr` | 滤波后电流 RMS / σI，区分噪声水平与持续非零电流 |
| `step_bic_gain` | 单变点常值模型相对常值/线性趋势模型的正则化 BIC 改善量 |
| `transition_fraction` | 从前水平 10% 到后水平 90% 的跃迁宽度 / 周期长度 |
| `plateau_fraction` | 排除过渡带与复位边沿后的后段长度 / 周期长度 |
| `post_current_std`, `post_stability_ratio` | 后段波动与噪声范围内的样本占比 |
| `voltage_drop_snr`, `voltage_collapse_ratio` | 同一变点前后电压下降与相对平台水平 |

周期首尾各 5% 不参与转折计数，防止固定开关/复位边沿主导振荡结果。变点候选位于周期的 5%–95%；变点平台评价进一步排除过渡带和末端复位。模型不使用单个最大 `di/dt`。

常值/线性模型与单变点模型通过累计和在 O(N) 内计算残差。当前使用：

\[
G=N\log\frac{SSE_{baseline}+N\sigma_I^2}{SSE_{step}+N\sigma_I^2}-\log N.
\]

`G>0` 说明单变点模型得到支持；这不等于短路，必须继续检查平台和电压。

`energy_J` 保留绝对功率的梯形积分作为活动能量代理，新增 `energy_signed_J=∫UI dt`。两者均使用真实时间轴，不参与核心分类。净加工能量还依赖电压、电流的极性定义、传感器标定和功率边界，不能仅凭负电流就取绝对值后作为真实加工能量。

删除 `di_dt_max` 和原先固定幅值交叉的 `I_rise_time`。`current_high_ratio/current_high_std/current_high_time` 保留为兼容描述量（幅值阈值为当前周期峰值的一半），退出分类和短路候选排序。相应旧列与新列定义不完全相同，不宜与旧统计直接混用。

## 5.4 基于电流动态行为的状态筛查

顺序如下：

1. **数据质量异常** → `abnormal_discharge`，输出具体质量原因。
2. **电流在噪声水平且存在施加电压证据** → `open_circuit`。无电压和无电流的周期不直接视为开路。
3. **电流显著跃迁后稳定且电压同步下降并稳定** → `short_circuit` 建议。要求变点模型获支持、幅值增加、跃迁足够快、后段足够长、后段电流/电压噪声水平内稳定、电压相对前水平降低、没有持续电流振荡。这是“短路形态”筛查，不能证明长平台一定是物理短路。
4. **有持续电流振荡及显著电压变化** → `effective_discharge` 建议。当前电压变化证据不是严格的电流—电压耦合检验；同频驱动、测量串扰也可能满足，需要实验标签确认。
5. **其余非零电流或证据不充分/混合形态** → `abnormal_discharge`，作为待复核类别。恒定大电流不会被判开路，单调漂移不会仅因幅值大而判短路。

`short_score` 是上述十项短路条件的满足比例，**不是概率，也不是分类置信度**。只有全部条件满足才给出短路建议；候选排序排除开路和损坏周期，其余仍可能是有效/异常放电。

本模型仍包含可见的统计/形态参数：4 倍噪声界、五点中值滤波、12 个窗口、至少 4 次转折、25% 振荡覆盖、40% 后平台、相对电压降低至前水平的一半等。这些是待实验验证的模型假设，不是“无参数”或“已学习出的边界”。实现避免固定的 3 A/20 A/10 V 判据，但不能仅凭自适应噪声估计宣称已实现机器学习。后续应根据跨实验标注做训练与评估，不继续逐张波形手调这些参数来制造合理分类数量。

## 5.5 状态统计、人工复核与后续学习

输出包括：

- `放电状态结果.csv`：四类建议、动态特征、质量原因、分类理由、边界、模型版本、`review_required=True`。
- `识别模型参数.json`：本次运行的模型版本、统计/形态参数及零电流偏置，明确记录尚未完成实验标签验证。
- `状态特征统计.csv`、`各状态特征均值.csv`：新增动态特征的分布及分状态均值，缺失特征标记有效样本数。
- `短路候选排序.csv`、`短路候选图/`：待核实候选与有符号电流双子图。
- `状态验证/批次目录/`：每类默认 10 张图、`人工复核清单.csv` 和 `状态样本统计.csv`。

每类按特征分布确定性抽取不同位置的样本，不只展示最典型的波形。若某类不足 10 个，输出现有数量并标记 `insufficient`；零样本不会生成虚构图片。每次生成独立复核批次，保留已有人工填写内容。四类不被强制要求同时出现。

人工在 `reviewed_state/review_notes` 填写真实标签、判断依据及不确定性。建议结合电极状态、加工参数、设备日志标注，保留 `uncertain` 而不是勉强归类。至少需要确认的开路、短路、有效和异常样本，尤其需要有反例的稳定长平台和负电流振荡。

后续可把稳定特征表作为训练输入，分离波形模型与分类器，使用监督模型。按**实验文件/加工工况**划分训练、验证和测试，避免相邻周期泄漏；仅用训练集选择参数。报告混淆矩阵、各类 precision/recall/F1、短路误报/漏报以及未知样本比例。样本图复核只覆盖部分周期，不能直接作为全数据准确率证明。

## 当前验证范围

`tests/test_discharge_states.py` 使用已知构造方式的合成波形验证：四类形态、电流符号/增益变化、负电流振荡、短路电压证据、孤立尖峰、阶跃后的振荡/漂移、慢振荡、零点校准、真实采样率积分、坏点、无周期、边界校验、CSV/统计/候选联动和复核批次保留。

这些是算法行为与软件回归测试。尚未提供原始实验 CSV、周期人工标签及传感器标定，原实验中 3514/1145 的类别数量和 cycle 4582/2330 都未重新计算或确认。

在当前 Python 3.12 云实例中，26 项 unittest 已通过。额外执行了 128,820 点合成 CSV 的真实主程序全流程，自动检测得到 58 个完整周期，周期点数中位数为 2147；类别不足会正常报告，不强制产生所有类别。

另在 10,000,000 点合成信号上单独运行状态模块，处理 4657 个完整周期（9,998,579 点；1421 点不足一个周期未参与），耗时约 5.832 秒，整个进程峰值 RSS 约 719.4 MiB。该测量**不含 CSV 读取、FFT 周期检测和绘图**，不是完整实验分析耗时或准确率。它只说明当前实例中已执行过相应规模的特征提取/分类，性能随机器和数据形态而变。
